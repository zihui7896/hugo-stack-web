# hugo-stack-web

1. git clone git@github.com:zihui7896/hugo-stack-web.git
2. 下载自己系统的hugo.exe  [https://github.com/gohugoio/hugo](https://github.com/gohugoio/hugo/releases/tag/v0.161.1)
hugo server -D / hugo server   构建并运行 

hugo new post/*/index.md   新建文章
